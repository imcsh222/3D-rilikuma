# 互動式 3D 慵懶拉拉熊玩偶 (Interactive 3D Rilakkuma Plush)

純原生零外部依賴 WebGL SDF 即時光線步進（Raymarching）互動式 3D 絨毛玩偶專案。

## 特色功能
- **還原參考圖經典側躺造型**：精準重現拉拉熊慵懶側躺比例、短絨毛光澤（Velvet Sheen）、玩偶車縫線、黃色耳墊／掌墊與背後隱藏小拉鍊彩蛋。
- **360° 自由檢視**：滑鼠／觸控拖曳旋轉、滾輪縮放。
- **軟Q麻糬按壓物理**：點擊鼻子、白肚肚、耳朵或四肢會觸發阻尼彈簧凹陷與回彈動畫，也可切換「連續揉捏模式」。
- **4 種姿勢與 4 種表情**：支援「經典側躺」、「仰躺午睡」、「乖乖坐姿」、「趴趴踢腿」平滑四元數插值切換。

## 開啟方式
直接以瀏覽器開啟 `index.html`，或在目錄下啟動本機伺服器：

```bash
python3 -m http.server 8080
```
